## Contesto

Tre problemi rilevati durante il testing reale post-v0.5.8:

1. **La cartella di quarantena non era trovabile** — il backend spostava i file con successo (moved > 0, failed = 0) ma l'utente non sapeva dove fossero finiti. Nessun feedback sul path effettivo usato da Rust.

2. **La versione era hardcoded in tre posti** — `V3.4.1 PRO` nella sidebar (sbagliata!), `v5.8` nel label del Cleaner, `0.5.9` nell'appStore. Ogni bump manuale era un rischio di dimenticare un punto.

3. **"GROUPS DETECTED" non era chiaro** — l'utente chiedeva: "che si intende per Groups?". Il contatore non spiegava il concetto.

## Fix 1 — Quarantine Path nella UI

### Problema

L'utente vedeva "2 moved, 0 failed" ma non trovava la cartella `_NonConform` o `_Duplicates`. Il backend Rust creava la cartella e spostava i file, ma il path effettivo non veniva mai comunicato al frontend.

Il path poteva essere:
- Default: `<workspace>/_NonConform` o `<workspace>/_Duplicates`
- Custom: il path scelto dall'utente dal dialog di sistema

In entrambi i casi, il risultato non includeva il path e l'utente doveva indovinare.

### Fix applicato

**`src-tauri/src/cleaner.rs`** — aggiunto `quarantine_path: String` a `QuarantineResult`:

```rust
#[derive(Debug, Serialize, Deserialize)]
pub struct QuarantineResult {
    pub moved: u64,
    pub failed: u64,
    pub quarantine_path: String,  // path effettivo della cartella (v0.5.9)
}
```

La funzione `quarantine_non_conform_impl` ora restituisce il path reale:

```rust
let quarantine_path_str = quarantine_dir.to_string_lossy().to_string();
Ok(QuarantineResult { moved, failed, quarantine_path: quarantine_path_str })
```

**`src-tauri/src/duplicates.rs`** — stesso fix per `DuplicateResolveResult`:

```rust
#[derive(Debug, Serialize, Deserialize)]
pub struct DuplicateResolveResult {
    pub moved: u64,
    pub failed: u64,
    pub quarantine_path: String,  // path effettivo (v0.5.9)
}
```

**`src/store/appStore.ts`** — `quarantine_path: string` già aggiunto in precedenza alle interfacce TypeScript corrispondenti.

**`src/components/modules/CleanerModule.tsx`** — nella schermata "Quarantine Complete" e "Resolve Complete" aggiunto un blocco che mostra il path effettivo:

```tsx
<div className="max-w-lg mx-auto mb-8 p-3 border border-industrial-border/50 bg-black">
  <p className="text-[9px] font-mono text-industrial-text-dim uppercase tracking-widest mb-1">Files moved to</p>
  <p className="text-[11px] font-mono text-industrial-cyan truncate">{ncQuarantineResult.quarantine_path}</p>
</div>
```

Stesso blocco per `dupResolveResult.quarantine_path`.

## Fix 2 — Versione dinamica da Tauri (elimina hardcoded)

### Problema

La versione era hardcoded in tre posti:
- `MainLayout.tsx` line 68: `V3.4.1 PRO` (completamente sbagliata — retaggio di un vecchio template)
- `CleanerModule.tsx`: `Sanitization Pipeline v5.8`
- `appStore.ts`: `appVersion: '0.5.9'` (default statico, richiede aggiornamento manuale)

### Fix applicato

**`src/store/appStore.ts`** — `appVersion` e `setAppVersion` erano già stati aggiunti nell'interfaccia. Il default `'0.5.9'` è solo un fallback temporaneo prima che Tauri risponda.

**`src/App.tsx`** — aggiunta chiamata `getVersion()` da `@tauri-apps/api/app` all'inizio dell'inizializzazione:

```tsx
import { getVersion } from "@tauri-apps/api/app";

// In init():
const version = await getVersion();
setAppVersion(version);
```

`getVersion()` legge `version` da `tauri.conf.json` — unica fonte di verità. Ogni bump del manifesto si propaga automaticamente a tutta la UI senza modificare i componenti.

**`src/components/layout/MainLayout.tsx`**:

```tsx
const { currentModule, setModule, systemStatus, appVersion } = useAppStore();
// ...
<p ...>V{appVersion}</p>
```

**`src/components/modules/CleanerModule.tsx`**:

```tsx
const { ..., appVersion } = useAppStore();
// ...
<p ...>Sanitization Pipeline v{appVersion}</p>
```

## Fix 3 — Spiegazione "Groups" nei Duplicati

### Problema

Il contatore nella Step 2 Duplicates mostrava `N groups` senza spiegare cosa fosse un gruppo. L'utente chiedeva: "cosa si intende per Groups?".

### Fix applicato

Aggiunta una riga esplicativa sotto il contatore:

```tsx
<div className="flex flex-col gap-0.5">
  <span className="text-[10px] font-mono text-industrial-text-dim uppercase">{duplicateGroups.length} groups detected</span>
  <span className="text-[8px] font-mono text-industrial-text-dim/60 uppercase">A group = 2+ files identified as duplicates of each other</span>
</div>
```
