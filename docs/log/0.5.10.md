## Contesto

Durante un test reale su `C:\Users\Utente\Music\Genesis`, la funzione "Resolve Duplicates" ha rinominato 419 file nella stessa cartella sorgente aggiungendo `_1` al filename invece di spostarli in `_Duplicates/`. Il log confermava:

```
SPOSTATO: Abacab - Genesis.flac → C:\Users\Utente\Music\Genesis\Abacab - Genesis_1.flac
```

**Causa**: l'utente aveva cliccato "Change" sulla destinazione e selezionato la cartella Genesis stessa (uguale al workspace). Il backend Rust ha usato quella cartella come `quarantine_dir`. Poiché i file omonimi esistevano già lì, `collision_safe_path` ha aggiunto `_1` a tutti — operazione tecnicamente riuscita ma semanticamente errata.

**I file non sono andati persi** — sono nella stessa cartella con `_1` nel nome. Ma l'errore era evitabile con una guardia a monte.

---

## Fix 1 — Guardia: workspace = destinazione è vietato

In `handleBrowseNcDest` e `handleBrowseDupDest`, dopo la selezione via dialog di sistema, viene confrontato il path scelto con `workspacePath`. Se sono uguali, l'operazione viene annullata e viene loggato un errore esplicito:

```tsx
if (selected === workspacePath) {
  addLog('error', 'Invalid destination: cannot use the source workspace as destination. A subfolder will be created automatically.');
  return;
}
```

Il log appare nel pannello live in rosso, rendendo chiaro il motivo del rifiuto.

---

## Fix 2 — Badge "AUTO — subfolder of source"

Quando la destinazione è quella di default (nessun override custom), entrambe le righe di destinazione mostrano ora un badge ambra:

```
AUTO — subfolder of source
```

Il badge sparisce non appena l'utente imposta una destinazione custom. Il pulsante cambia da `Override` a `Change` per riflettere lo stato.

**Significato visivo**:
- Badge presente = il sistema creerà automaticamente `_NonConform/` o `_Duplicates/` dentro il workspace sorgente
- Badge assente = l'utente ha sovritto il path manualmente

---

## Fix 3 — Pulsante "Override" invece di "Change" (default)

Quando si usa la destinazione automatica, il pulsante mostra `Override` invece di `Change`. Questo comunica che stai per cambiare un comportamento automatico — non una semplice modifica di path.

## Nota post-incidente: recupero file Genesis

I file rinominati con `_1` in `C:\Users\Utente\Music\Genesis\` sono i "loser" duplicati che avrebbero dovuto andare in `_Duplicates/`. Sono fisicamente intatti — solo il nome è cambiato. Per ripristinare la situazione originale occorre rinominare tutti i `*_1.flac` rimuovendo il suffisso, oppure trattare quella cartella come già "ripulita" dai duplicati (i file senza `_1` sono le versioni best-pick).
